# TaxMatch by ScanMyData

Τοπική εφαρμογή για λογιστικά γραφεία: παρακολουθεί καθημερινά τα φορολογικά/λογιστικά/εργατικά νέα
(taxheaven, e-forologia), τα αντιστοιχίζει με τους πελάτες σας βάσει **ΚΑΔ, κατηγορίας βιβλίων, καθεστώτος ΦΠΑ και νομικής μορφής**
και σας δείχνει *ποιον αφορά τι και μέχρι πότε*. Τα δεδομένα των πελατών μένουν στον υπολογιστή σας.

- **Αρχική** — ενημερωτικό ανά άρθρο ή ανά πελάτη, ταξινομημένο με την πλησιέστερη προθεσμία πρώτη, 👍/👎 σε κάθε match
- **Πελάτες** — εισαγωγή από Excel ή με ΑΦΜ (αυτόματη ανάκτηση από ΓΕΜΗ/ΑΑΔΕ), φίλτρα, προφίλ
- **Ημερολόγιο** — γενικό φορολογικό ημερολόγιο + προθεσμίες από νέα που αφορούν πελάτες
- **Νέα & Matches** — όλα τα άρθρα και το *γιατί* αφορούν κάθε πελάτη
- **Καθημερινός έλεγχος** στο παρασκήνιο (Windows Task Scheduler) ακόμη κι αν η εφαρμογή είναι κλειστή

## Εγκατάσταση (χρήστες)
Τρέξτε το `TaxMatch-Setup-x.y.z.exe` (δεν απαιτεί δικαιώματα διαχειριστή). Στις **Ρυθμίσεις** δώστε:
API key **Groq** (ή OpenRouter) για την ανάλυση άρθρων· προαιρετικά API key **Business Portal (ΓΕΜΗ)** και/ή λογαριασμό **TAXISnet** του γραφείου για αυτόματη συμπλήρωση στοιχείων πελατών.
Τα credentials αποθηκεύονται κρυπτογραφημένα (Fernet, κλειδί προστατευμένο με Windows DPAPI).

## Ανάπτυξη
```powershell
uv venv --python 3.12 .venv
uv pip install --python .venv\Scripts\python.exe -r requirements-dev.txt
.venv\Scripts\python.exe -m pytest        # tests
.venv\Scripts\python.exe -m taxmatch      # εκκίνηση
powershell -ExecutionPolicy Bypass -File packaging\build.ps1   # installer -> installer-output\
```
Δείτε το [`CLAUDE.md`](CLAUDE.md) για αρχιτεκτονική, κανόνες και **ανοιχτά θέματα**.

## Ασφάλεια
Ο server ακούει μόνο στο `127.0.0.1` σε τυχαία θύρα και δέχεται αιτήματα μόνο με το μυστικό token της τρέχουσας εκκίνησης
(προστασία από άλλες διεργασίες, DNS rebinding και CSRF). Δεν υπάρχει telemetry· προς τα έξω φεύγουν μόνο: τα RSS feeds, το κείμενο των άρθρων προς τον πάροχο LLM που επιλέγετε, και τα lookups ΓΕΜΗ/ΑΑΔΕ.
