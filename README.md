# TaxMatch by ScanMyData

Τοπική εφαρμογή για λογιστικά γραφεία: παρακολουθεί καθημερινά τα φορολογικά/λογιστικά/εργατικά νέα
(taxheaven, e-forologia), τα αντιστοιχίζει με τους πελάτες σας βάσει **ΚΑΔ, κατηγορίας βιβλίων, καθεστώτος ΦΠΑ και νομικής μορφής**
και σας δείχνει *ποιον αφορά τι και μέχρι πότε*. Τα δεδομένα των πελατών μένουν στον υπολογιστή σας.

- **Αρχική** — ενημερωτικό ανά άρθρο ή ανά πελάτη, ταξινομημένο με την πλησιέστερη προθεσμία πρώτη, 👍/👎 σε κάθε match
- **Πελάτες** — «Νέος πελάτης» με ΑΦΜ: η **επωνυμία έρχεται αυτόματα** από το VIES (χωρίς API key)· εισαγωγή από Excel (και μπλοκ «Κωδικοί Υπηρεσιών μέσω Internet»)·
  **κωδικοί TAXISnet ανά πελάτη, προαιρετικά** (ατομικά ή μαζικά)· **αυτόματη ανάκτηση και αποθήκευση** από το Μητρώο ΑΑΔΕ (ΚΑΔ, είδος, ενεργός/διακοπή εργασιών, ΔΟΥ, κατηγορία βιβλίων, ΦΠΑ) με ΓΕΜΗ ως fallback·
  ειδοποίηση μέσα στην εφαρμογή όταν κάποιοι κωδικοί είναι λάθος· επιλογή/φίλτρο/μαζικές ενέργειες
- **Ημερολόγιο** — γενικό ημερολόγιο (taxheaven) + **κανονικές προθεσμίες** (ΦΠΑ μηνιαία/τριμηνιαία ανά πελάτη, VIES, Intrastat, OSS/IOSS, ΑΠΔ, Ε4…) + προθεσμίες από νέα
- **Νέα & Matches** — όλα τα άρθρα (taxheaven, e-forologia, ot.gr, forologikanea, naftemporiki, capital, ΠΟΕ-ΔΟΥ) και το *γιατί* αφορούν κάθε πελάτη·
  ενημέρωση περιλαμβάνει και **θέματα μισθοδοσίας/εργατικών** από την πλευρά της επιχείρησης· κλικ σε είδηση ανοίγει πρώτα **προεπισκόπηση μέσα στην εφαρμογή**, με τον εξωτερικό σύνδεσμο από κάτω
- **Native desktop εφαρμογή (PySide6/Qt)** — ίδια εμφάνιση με το **timologio downloader** (σκούρο/φωτεινό θέμα, πλευρικό μενού, φίλτρα στηλών στυλ Excel), όχι browser/webview· έχει **εγχειρίδιο (PDF)** και **ξενάγηση (page tour)** για τη μελλοντική ενσωμάτωση στη σουίτα ScanMyData
- **Καθημερινός έλεγχος** στο παρασκήνιο (Windows Task Scheduler) ακόμη κι αν η εφαρμογή είναι κλειστή
- **LLM ανάλυση άρθρων**: προτιμώνται πάντα **δωρεάν μοντέλα**, με αυτόματη εναλλαγή αν κάποιο σταματήσει να δουλεύει· μόνο αν κανένα δωρεάν δεν λειτουργεί, η εφαρμογή προτείνει ρητά μετάβαση σε πληρωμένο μοντέλο (ποτέ σιωπηλά)

## Εγκατάσταση (χρήστες)
Τρέξτε το `TaxMatch-Setup-x.y.z.exe` (δεν απαιτεί δικαιώματα διαχειριστή). Στις **Ρυθμίσεις** δώστε:
API key **OpenRouter** (ή Groq) για την ανάλυση άρθρων· προαιρετικά API key **Business Portal (ΓΕΜΗ)** και/ή λογαριασμό **TAXISnet** του γραφείου για αυτόματη συμπλήρωση στοιχείων πελατών.
Τα credentials αποθηκεύονται κρυπτογραφημένα (Fernet)· προαιρετικά μπορείτε να ορίσετε **κύριο κωδικό** (Argon2id) που προστατεύει το κλειδί κρυπτογράφησης.

## Ανάπτυξη
```powershell
uv venv --python 3.12 .venv
uv pip install --python .venv\Scripts\python.exe -r requirements-dev.txt
.venv\Scripts\python.exe -m pytest        # tests (incl. GUI smoke tests, offscreen)
.venv\Scripts\python.exe -m taxmatch      # εκκίνηση της native εφαρμογής (PySide6)
powershell -ExecutionPolicy Bypass -File packaging\build.ps1   # installer -> installer-output\
```
Δείτε το [`CLAUDE.md`](CLAUDE.md) για αρχιτεκτονική, κανόνες και **ανοιχτά θέματα**.

## Ασφάλεια
Η εφαρμογή είναι **native desktop (PySide6/Qt)** — δεν ανοίγει σε browser. Δεν υπάρχει telemetry· προς τα έξω φεύγουν μόνο: τα RSS feeds, το κείμενο των
άρθρων προς τον πάροχο LLM που επιλέγετε, και τα lookups ΓΕΜΗ/ΑΑΔΕ/VIES. Ο εσωτερικός Flask server (`--serve`) που χρησιμοποιείται μόνο για
ανάπτυξη/tests ακούει αποκλειστικά στο `127.0.0.1` με per-launch token cookie.
